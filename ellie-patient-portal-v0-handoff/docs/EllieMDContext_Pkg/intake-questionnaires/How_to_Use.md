# How to Use

Source: 3.0_EllieMD_Questionnaire_Source_of_Truth.xlsx

**Q1.0** What is your height?
- Format: Text Box (2 boxes) 
- Answers: Feet
Inches

**Q# Column** Question Column
- Format: Answer Format Column
- Answers: Answers/Place Holder Text Column
- **Conditions: Conditions Column**
- Popup: Disqualified Pop Up Text

**QQuestion Number** Main Question Text
- Format: UI Component Types: 
- Answers: For dropdowns and radios, use these as the visible label text.
- **Conditions: Disqualification Rules:
If a condition like “If No, DISQUALIFIED” is met, trigger a modal pop-up using the Disqualified Pop-Up Text **
- Popup: Trigger a modal pop-up using the Disqualified Pop-Up Text with an exit pathway
